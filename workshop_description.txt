[h1]Primary Monitor[/h1]

[b]Start Teamfight Manager 2 centered on your Windows primary monitor.[/b]

Primary Monitor positions the game window once during launch, then leaves later manual movement untouched.

[h2]Features[/h2]

[list]
[*] Moves the game window to the Windows primary monitor.
[*] Centers it within the monitor's usable work area.
[*] Preserves the current window size.
[*] Retries failed startup lookups at a bounded interval.
[*] Stops after the first successful placement.
[/list]

The mod does not change resolution, fullscreen behavior, or display settings.

[h2]Compatibility[/h2]

[b]Tested with:[/b] TFM2 0.5.2–0.5.4

Requires Windows and the game window title Teamfight Manager2.

[h2]Setup[/h2]

[list]
[*] Subscribe to and enable Primary Monitor.
[*] No configuration is required.
[*] Restart the game when prompted.
[/list]
