# Security policy

Primary Monitor invokes a small set of Windows window-management APIs inside
the game process. It does not intentionally access career saves, credentials,
the clipboard, or the network.

Report a vulnerability privately through this repository's **Security** tab
using **Report a vulnerability**. Include the game version, mod version, and a
minimal reproduction. Do not include personal files or sensitive paths.

Ordinary positioning and compatibility bugs can use a public issue.
