## Steam Workshop

**Title**

Primary Monitor

**Short description**

Center Teamfight Manager 2 on the Windows primary monitor once during launch,
then leave manual window movement untouched.

**Full description**

Primary Monitor is a focused quality-of-life mod for multi-monitor Windows
setups.

FEATURES

• Move the game to the Windows primary monitor during startup  
• Center it inside the monitor's usable work area  
• Preserve the current window size  
• Stop intervening after the first successful placement  
• Never read or modify career saves

COMPATIBILITY

Primary Monitor 0.1.1 is built for Teamfight Manager 2 0.5.2 on Windows.
